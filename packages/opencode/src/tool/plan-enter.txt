Use this tool when Build mode should switch to Plan before implementation.

This tool will ask the user if they want to switch to Plan mode to clarify requirements and create an implementation plan.

If this tool is needed, call it immediately before doing anything else. Do not plan, research, inspect files, or take any other action first.

Call this tool:
- When the task has just started and no approved plan exists
- When requirements are missing or unclear for new or substantial swarm work
- When the user request needs planning before file edits

Do NOT call this tool:
- If the user has already approved a plan
- If the task is a small, clear implementation detail
- After you have already started making file changes
